# Sri Balaji Hospital, Tanuku — static website

Single-page public website for Sri Balaji Hospital, Sajjapuram, Andhra Pradesh 534211. The site is frontend-only and static-hostable.


## Assets

- `public/assets/sri-balaji-hospital-logo.png` — hospital logo (trimmed, transparent), used in the header, hero badge and footer; favicons are generated from it
- `public/assets/hero-sri-balaji-building.webp` — building photo, used in the hero background and as the first gallery photo
- `public/assets/dr-billygraham-deepati.webp` — doctor photo, cropped to a 4:5 portrait
- `original-assets/` — the supplied files, unmodified
- `public/assets/photos/*.svg` — placeholders for the remaining gallery photos (reception, consultation room, waiting area, laboratory)
- `src/mobile.css` — phone layout refinements (loaded last)
